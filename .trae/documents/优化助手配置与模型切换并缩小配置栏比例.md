## 模型管理现状

- 发送时使用当前 `config.model` `src/renderer/src/components/AgentWorkbench.vue:111-120`
- 若出现“只能默认模型”：常见原因
  - 模型列表未加载（IPC未就绪）；下拉为空时仍显示默认值
  - 选项值与后端实际模型名不一致（例如需要不带版本别名）；请求被后端回退为默认
  - 无 API Key 时后端走模拟响应，用户感知为没有变化
