## 1. 数据看板筛选区布局与尺寸修复
- 布局：为筛选容器新增样式
  - `.filter-container { display:flex; flex-wrap:wrap; gap:12px; align-items:center }`
  - `.filter-item { flex: 1 1 220px; min-width:220px }`
- 尺寸：统一控件尺寸与间距
  - 为 `n-button`、`n-input`、`n-select`、`n-date-picker` 设置 `size="large"`
  - 保持 `n-card` 宽度 `100%` 与内容内边距（避免控件贴边）
- 响应式：在较小宽度下控件自动换行，按钮始终完整展示图标与文字

## 2. 数据分析页图表显示与暗色适配
- 图表显示稳定：
  - 统一 Canvas 尺寸：`canvas { width:100% !important; height:320px !important }`
  - `Chart` 配置 `responsive:true` 与 `maintainAspectRatio:false`
  - 在渲染后调用 `chart.resize()`，并在窗口尺寸/Tab切换后重绘
- 暗色主题适配：
  - 将硬编码白色背景替换为 CSS 变量：`background-color: var(--color-card-bg)`, `color: var(--color-text)`, `border-color: var(--color-border)`（如 `.header`, `.stat-card` 等）
  - 读取主题变量作为 Chart 颜色：
    - 轴/标签/网格：`color: var(--color-text)`、`grid.color: var(--color-border)`
    - 数据集颜色：使用半透明色并在暗色下提高对比度
- 交互优化：若切换主题（浅/深），在 `displayCharts()` 后统一刷新图表颜色

## 3. 智能助手页面暗色适配与工作流路径展示
- 暗色适配：
  - `.chat-messages { background-color: var(--color-card-bg) }`
  - `.message.agent .message-content { color: var(--color-text); border-color: var(--color-border) }`
  - `.chat-input-container { background: var(--color-card-bg); border-top: 1px solid var(--color-border) }`
  - 用户消息气泡背景用 `var(--color-button-primary)`，文字用浅色以保证对比度
- 工作流路径展示：
  - 在每次回复前，渲染“工作流轨迹”组件，显示：
    - `steps[]`: { type: 'think'|'tool'|'result', title, detail, timestamp }
    - 工具调用的 `toolName`、`args`（脱敏后的关键参数）与结果摘要
  - 在消息结构存储中增加 `trace` 字段，页面提供“展开/折叠工作流”交互
- 会话结构化存储设计：
  - 单条消息：`{ role, content, time, trace?: Step[], toolCalls?:[], toolResults?:[] }`
  - 会话：`{ id, createdAt, messages: Message[], meta: { permissions, model, temperature } }`
  - 先存内存与本地（通过 IPC 写入 `userData` 下的 JSON），后续可替换为更安全的存储（不含密钥）

- 提取筛选组件：`FilterBar.vue`

- 提取卡片组件：`DataCard.vue`

- 在数据看板替换原有 DOM；在助手页复用用于展示检索结果

## 5. 智能助手架构升级（为后续权限与工具调用预留）
- IPC 接口：
  - `assistant:invoke-tool(payload)`：调用受控工具（日志检索、统计数据、导出等）
  - `assistant:chat(payload)`：与 LLM 对话，支持函数调用（工具列表）与返回 `trace`
  - `assistant:stream(payload)`：流式传输分片消息，用于长回复
- 工具注册与权限：
  - 在主进程维护工具注册表，声明 `name`, `schema`, `handler`, `permissions`
  - 渲染层仅声明意图，主进程做参数校验与权限过滤
- 数据访问：复用 `load-data`, `analyze-data` 并以工具形式暴露给助手；统一结果结构以便渲染
- LLM 对接（阿里云）：
  - 采用可注入 `baseURL` 与 `apiKey`，从环境变量或安全存储读取；不写入仓库与代码
  - 主进程实现 `llmClient` 封装（支持流式与函数调用），输出标准 `trace`
