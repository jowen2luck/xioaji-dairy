## 目标
- 将配置与提示词统一管理到独立模块，便于维护与扩展。
- 将每轮工具链调用与助手回复绑定展示，折叠在消息气泡前部。
- 为 JSON 结果提供“结构化可读”的展示：属性清晰分组、列表表格化、原始 JSON 可查看。

## JSON 展示策略
- 类型识别：
  - 字符串：若疑似 JSON（以 { 或 [ 开头），尝试 `JSON.parse`，失败则按纯文本显示。
  - 对象：使用“属性描述”组件展示（键值对、分组、顺序）。
  - 数组：
    - 元素为对象：表格化展示（列为属性名并可排序筛选）；
    - 元素为原始值：以列表展示。
- 通用组件：
  - 对象：`n-descriptions`（每个键一行），长值折叠，支持复制。
  - 数组对象：`n-data-table`，默认显示前 50 条，支持“展开更多”。
  - 原始 JSON：`n-code`（或 `<pre>`）原样查看，切换按钮“查看原始 JSON”。
- 字段优先序与别名：
  - 新增 `templates` 描述文件，为已知工具结果提供“字段别名、显示顺序、隐藏字段”。
  - 未匹配时使用“自动推断”：按常见关键字段（如 `id/name/title/time/score`）优先。
- 大数据优化：值长度超过 N 字符折叠；数组超过 N 项分页或“增量加载”。

## 模块设计
- `src/renderer/src/utils/jsonView.ts`
  - `isJSONText(str)`，`safeParse(str)`
  - `renderObject(obj, template?)`：生成 `n-descriptions` 所需数据结构（别名、排序、隐藏处理）。
  - `renderArray(arr, template?)`：生成 `n-data-table` 列与数据（推断列集与顺序）。
  - `renderRaw(objOrStr)`：原始 JSON 美化（2 空格缩进）。
- `src/renderer/src/config/templates.ts`
  - 结构：`{ toolName: { labelMap: Record<string,string>, order: string[], hidden: string[] } }`
